# MomDiary Medical Library CDN Assets (GitHub + jsDelivr)

> **Dedicated Public Assets & CDN Repository for MomDiary Doctor Academic Library**
> Lưu trữ vĩnh viễn hình ảnh y khoa nguyên bản và các bản đối chiếu song ngữ lâm sàng của AI Minh Translate.

## Cấu trúc lưu trữ
- `/images/<book-id>/...`: Toàn bộ hình ảnh y khoa nguyên bản (ultrasound, flowcharts, clinical figures).
- `/articles/<book-id>.json`: Dữ liệu bài viết song ngữ đối chiếu kèm khối trích dẫn học thuật.

## CDN URL Mapping (via jsDelivr)
- Hình ảnh:
  `https://cdn.jsdelivr.net/gh/bacsiha1989/md-library-assets@main/images/<book-id>/<image-file>`
- Bài viết JSON:
  `https://cdn.jsdelivr.net/gh/bacsiha1989/md-library-assets@main/articles/<book-id>.json`

## Giấy phép & Sử dụng
Tài sản học thuật phục vụ tra cứu lâm sàng và đào tạo y khoa nội bộ MomDiary theo Điều 25 Luật SHTT Việt Nam và nguyên tắc Fair Use quốc tế.
